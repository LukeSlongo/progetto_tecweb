# Guida ai Test (PHPUnit) per il Backend

##  1. Setup Rapido (Da fare solo la prima volta)
Apri il terminale nella root del progetto (`progetto_tecweb/`) e lancia:

    ```bash
    composer install
    ```

## 2. Lanciare i test
Dalla root del progetto, lancia il comando:

    ```bash
    ./vendor/bin/phpunit
    ```
