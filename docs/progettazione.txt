Applicazione ibrida: server-side rendering con elementi dinamici gestiti frontend da JS

1. rotte web -> caricamento delle pagine: renderizza il template e restituisce l'html
2. rotte API -> operazioni dinamiche per non ricaricare la pagina

Rotte web:
mostra loginPage:                                          GET   /login                                 (UserController->view_login)
elabora login:                                             POST  /login                                 (UserController->login)
mostra registerPage:                                       GET   /register                              (UserController->view_register)
elabora registrazione:                                     POST  /register                              (UserController->register)
logout (distrugge la sessione e torna alla loginPage):     GET   /logout                                (UserController->logout)

mostra pagina principale:                                  GET   /                                      (UserController->view_home)
mostra lista aule:                                         GET   /aule                                  (AulaController->view_aule_page)
mostra dettaglio aula:                                     GET   /aule/{id}                             (AulaController->view_aula_dettaglio)
mostra segnalazione form:                                  GET   /segnalazione                          (SegnalazioneController->view_report_form)
submit segnalazione:                                       POST  /segnalazione                          (SegnalazioneController->save)
delete segnalazione:                                       GET   /segnalazione/delete?id={id}           (SegnalazioneController->delete)
mostra dettaglio segnalazione:                             GET   /segnalazione/{id}                     (SegnalazioneController->view_report_detail)

mostra segnalazioni:                                       GET   /segnalazioni?status={status}          (SegnalazioneController->view_report)
mostra lista utenti:                                       GET   /utenti                                (UserController->view_utenti_list)
elimina utente:                                            GET   /utenti/delete?id={user_id}            (UserController->delete)
